## Findings

- **Precision at 4 is 0.75 for the Java JD.** Sample 11 ("good": every skill an exact match, but a diploma) ranks above sample 3 ("strong": PostgreSQL and Kafka only related, Microservices inferred), 91.9 to 89.2. Under the default weights the diploma costs 5 points and the indirect skills 10.8. Only raising education's weight to 0.2 changes that (see the weight table). The doc's defaults (40/30/20/10) were kept rather than tuned to one pair of samples.
- **Keyword-only: sample 7 (keyword stuffer) rises, sample 2 (synonyms) does not fall.** Sample 2's synonyms (k8s, Postgres) are all in the alias dictionary: tier 2, which the ablation keeps. The sample that leans on meaning is sample 3: it loses 15.6 points.
- **Spearman for the Data Scientist and Frontend JDs is low** because each has one strong sample and 12-13 equally "weak" ones, so the statistic mostly measures the order among the weak samples. In both, the strong sample ranks first, by 57 points or more.
- **Partial credit at 0.4, 0.5 or 0.6 gives the same rankings:** the half credit is not a fragile choice.

## Calibrated thresholds

| Parameter | Doc's start | Used | Why |
| --- | --- | --- | --- |
| Related-skill cosine (tier 3) | 0.80 | 0.58 | No related pair reaches 0.80 with this model; 0.58 keeps Kafka/RabbitMQ (0.59) and PostgreSQL/MySQL (0.62), drops Next.js/Node.js (0.55) and Java/Python (0.54) |
| Contextual cosine (tier 4) | 0.55 | 0.43 | The one described-but-unnamed skill (sample 3, Microservices) scores 0.46; the highest false one 0.40 |
| Semantic floor L / ceiling H | 0.20 / 0.70 | 0.30 / 0.47 | Mean raw score of the weak (0.295) and strong (0.473) sample/JD pairs: the doc's rule |
| Requirement covered / partial | 0.55 / 0.40 | 0.40 / 0.30 | A strong candidate's median best match is 0.40 with this model |
| Role relevance: relevant / partly | 0.55 / 0.40 | 0.55 / 0.42 | Sample 8's QA role scores 0.39 and must not count |
| Field-of-study cosine | 0.6 | 0.6 | Unrelated fields top out at 0.54 |
